Veluma publisher

Privacy policy

Effective 28 October 2026.

Who uses it

Veluma publisher is a private tool of the Veluma Videos YouTube channel. Only the channel owner uses it, on their own computer, for their own channel. It is not offered to other people, and it does not collect information about anyone else.

YouTube API Services

Veluma publisher uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What it accesses and why

With the owner's permission (the YouTube scope https://www.googleapis.com/auth/youtube.force-ssl), it:

  • reads the signed-in channel's ID, name and handle, to make sure it acts on the Veluma Videos channel and no other;
  • uploads the channel's own videos and sets their titles, descriptions, tags, playlists and publication time;
  • reads the status of those videos (for example whether a scheduled video is public), and the channel's uploads and playlists.

It does not read comments, messages, subscribers, analytics or any other person's data.

What it stores

The authorization (OAuth tokens) is stored only in a file on the owner's computer. It is not sent to any server other than Google's. The tool keeps a record of the channel's own videos (titles, publication times and YouTube video IDs) in the owner's private repository.

Sharing

Nothing obtained through YouTube API Services is sold, shared with third parties, or used for advertising. No cookies or analytics are used, and these pages set none.

Revoking access and deleting data

The owner can revoke the tool's access at any time on the Google Account third-party access page (also reachable through Google security settings). Deleting the local token file removes the stored authorization from the computer.

Changes and contact

Changes to this policy are published on this page with a new effective date. Questions: through the Veluma Videos YouTube channel.
